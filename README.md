# 📅 Leave Tracking and Management System

The **Leave Tracking and Management System** is a comprehensive web-based application designed to streamline the management of employee leave within an organization. This project leverages Google Apps Script and Google Sheets to provide a dynamic and interactive platform for both HR managers and employees.
<br><br>

### ✨ Features
#### For Employees
- **📊 Dashboard Access**: Employees can view their leave balance, recent leave applications, and leave history.
- **📝 Leave Application**: A simple interface to apply for leave, integrated with Google Forms.
- **📆 Calendar View**: See who is currently on leave within the organization.

#### For HR Managers
- **🖥️ HR Dashboard**: View and manage all pending leave applications with options to approve or reject.
- **🔍 Detailed Leave Information**: Access detailed information about each leave application, including employee details and leave history.
- **🔒 Role-Based Access**: Secure access to sensitive information, ensuring only authorized personnel can manage leave applications.
<br>

### 🛠️ Technical Overview
- **📜 Google Apps Script**: Handles server-side operations, including data retrieval and user authentication.
- **🌐 HTML/CSS/JavaScript**: Provides a responsive and interactive user interface, utilizing Tailwind CSS for styling.
- **📈 Google Sheets Integration**: Real-time data management and storage, ensuring up-to-date information is always available.
<br>

### 📁 File Structure
- **Calendar.html**: Displays the monthly leave calendar for employees.
- **Code.gs**: Contains server-side scripts for handling data operations and user authentication.
- **E_main.html**: Employee dashboard for viewing leave balances and history.
- **HR_applydetails.html**: Detailed view for HR managers to review individual leave applications.
- **HR_main.html**: Main dashboard for HR managers to manage leave applications.
<br>

### 🚀 Getting Started
1. **Setup Google Sheets**: Ensure you have the necessary Google Sheets set up with employee and leave data.
2. **Deploy Google Apps Script**: Deploy the `Code.gs` script to handle backend operations.
3. **Access the Application**: Share the application link with employees and HR managers for access.
